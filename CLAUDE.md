# Notes for editing this site

- Plain static HTML/CSS. No Jekyll, no build step. No JavaScript except the readings search (`assets/js/readings-search.js`, loaded only by `/readings/search/`, which reads `readings/search/readings.json`), the co-assignment network's click-to-highlight (`assets/js/readings-network.js`, only on `/readings/network/`) and, once switched on with `tools/set_goatcounter.py`, GoatCounter visit counting (self-hosted `assets/js/count.js`, no cookies). `.nojekyll` keeps GitHub Pages from processing files.
- Pages: `index.html` (About), `research/index.html`, `cv/index.html`, `readings/` (reading lists compiled from PhD syllabi: a navigation page plus one page per stream, and `sitemap.xml`; all generated, see `tools/readings/README.md`, never hand-edit), `404.html`; `publications/` only redirects to `/research/`.
- Header and footer markup is repeated in every page; change them everywhere at once.
- All styling lives in `assets/css/site.css`; colours and type sizes are tokens at the top (light and dark mode).
- Cache busting: pages link `site.css?v=…`. Bump that version in every HTML page whenever site.css changes, and add/bump `?v=` on any font or image URL whose file is replaced; otherwise returning visitors see stale styles.
- Readings: streams with many readings are split into sub-streams (tools/readings/subtopics.py + subtopics.json); rebuild with tools/readings/build_page.py. Streams and sub-streams carry two-level numbers (12, 12.1) that follow the theory tree's order. DOIs come from tools/readings/dois.py (Crossref) into dois.json; standardize.py formats every reference (APA 7) from the Crossref records and merges duplicates; hand corrections go in fixes.json and dois_manual.json.
- Research page groups every paper by stream (真 authenticity, 善 social issues, 美 aesthetics, plus a Book review section at the end), published first, then under review, then in progress. The CV lists the same papers by type (APA). Home has short stream summaries and News only (no publication list, by the owner's choice). Keep all of them in sync. Unpublished or in-preparation pieces the owner has not released (e.g. invited reviews) stay off the site.
- No CV PDF is published for now (owner's choice). `/cv/` still has print styles at the end of `site.css` if one is wanted later.
- Papers under review and work in progress are listed by short topic only, never by full title (owner's choice). The name is Zhongyuan Sun, without "Jowan".
- Fonts are self-hosted subsets (`assets/fonts/`); the CJK file only contains 孙中源, 真善美 and 影; re-subset it if new characters are needed. Do not switch to Google Fonts (blocked in mainland China).
- Deploy: `.github/workflows/deploy.yml` copies the repo to the `gh-pages` branch on every push to `main`, and sets each page's footer "Last updated Month Year" to the month of the last commit that changed that page (keep that footer wording).
- Preview locally with `python3 -m http.server` from the repo root (paths are root-relative).
